# Ubuntu 24.04.5 ARM64 v1 Acceptance Matrix

This matrix scopes the current four-control SSH assessment slice. The implementation dispatches only when the local identity reports Linux, `ID=ubuntu`, `VERSION_ID=24.04`, a `PRETTY_NAME` identifying Ubuntu 24.04.5, and `GOARCH=arm64`. Tests use injected identity/configuration data; they do not spoof the host or establish live behavior.

The four existing catalog entries are 5.1.19–5.1.22. Their mapping is corroborated by a secondary rendering. The official CIS Ubuntu 24.04 LTS Benchmark is version 2.0.0, but its PDF/profile has not been directly reviewed here and applicability to the precise Ubuntu 24.04.5 ARM64 target remains unconfirmed. This prototype is not a claim of full CIS compliance.

“Automated” and “passed” below refer to repository tests, not to a real target. A defined future case is not counted as passed because it appears in this matrix.

## Exit criteria and unresolved evidence

- The current automated tests establish unit-level dispatch, parser, finding, evidence, planning and denial behavior, plus an isolated local OpenSSH process check against temporary configuration files. The SSH service is never reloaded by these tests.
- The shared v1 matrix is defined; it is not evidence that every scenario passed at every level.
- Official benchmark PDF/profile review and formal Ubuntu 24.04.5 ARM64 control applicability remain prerequisites before describing the controls as formally compliant.
- A representative target integration run for this exact source/build and identity is not part of this batch. No privileged execute or rollback operation is authorized or performed here. The existing executor requires root and does not use the assessment-only sudoers command; an approved least-privilege helper/service design and disposable-VM validation are prerequisites.
